# Latest release

**`0.2.0` — 2026-09-28.** The notes are the `0.2.0` section of the root
[`CHANGELOG.md`](../../CHANGELOG.md#020---2026-09-28), published as
[the `v0.2.0` GitHub release](https://github.com/soimy/dsh-gist-settings/releases/tag/v0.2.0).

This file is the alias: when a new release note is added to the changelog and its version is bumped, this
page moves to that version. It exists so that a reader — or a link from elsewhere — has one stable place
to ask "what is the current release?" without knowing the version number in advance.

Everything merged since `0.2.0` is under [`[Unreleased]`](../../CHANGELOG.md#unreleased). That includes
the move of the runtime and the suites to TypeScript, the compiled `dist/` the Harness loads, the
type-check and per-version schema jobs in CI, and the compatibility declaration that lets the plugin load
on the `0.2.0` line of dsh. None of it is tagged yet; [the roadmap](../plans/2026-09-30-post-typescript-roadmap.md)
has the release as its first planned step.
